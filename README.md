# NTI — Machine Learning for Data Analysis

Tasks and final project for the NTI Machine Learning for Data Analysis track.

| Folder | Description |
|---|---|
| [Final_Project](./Final_Project) | India Air Quality — predicting RSPM (PM10) with a tuned XGBoost pipeline, deployed with Streamlit |
| [Task01_Adult_Census_Income](./Task01_Adult_Census_Income) | Adult Census Income — Classification: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting |
| [Task02_Ames_Housing_Dataset](./Task02_Ames_Housing_Dataset) | Ames Housing Dataset — Regression: Ridge, Lasso, Random Forest, Gradient Boosting |
| [Task03_Apartments_Prices_Dataset](./Task03_Apartments_Prices_Dataset) | Apartments Prices Dataset — Regression: Linear Regression, Decision Tree, Random Forest, Gradient Boosting |
| [Task04_Bank](./Task04_Bank) | bank — Classification: Logistic Regression, SVM, Random Forest, Gradient Boosting |
| [Task05_Car_Data](./Task05_Car_Data) | car data — Regression: Linear Regression, KNN, Random Forest, Gradient Boosting |
| [Task06_Customer_Segmentation_Classification](./Task06_Customer_Segmentation_Classification) | Customer Segmentation Classification — Classification: Logistic Regression, KNN, Random Forest, Gradient Boosting |
| [Task07_Healthcare_Dataset_Stroke_Data](./Task07_Healthcare_Dataset_Stroke_Data) | healthcare_dataset_stroke_data — Classification: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting |
| [Task08_House_Rent](./Task08_House_Rent) | House Rent — Regression: Linear Regression, Ridge, Random Forest, Gradient Boosting |
| [Task09_Attrition](./Task09_Attrition) | attrition — Classification: Logistic Regression, SVM, Random Forest, Gradient Boosting |
| [Task10_Diabetes_Patients_10000_Full](./Task10_Diabetes_Patients_10000_Full) | diabetes patients 10000 full — Classification: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting |
| [Task11_Laptop_Data](./Task11_Laptop_Data) | laptop Data — Regression: Linear Regression, Decision Tree, Random Forest, Gradient Boosting |
| [Task12_Used_Cars_Dataset](./Task12_Used_Cars_Dataset) | used cars dataset — Regression: Linear Regression, KNN, Random Forest, Gradient Boosting |
| [Task13_WiDS_Dataton](./Task13_WiDS_Dataton) | WiDS Dataton — Classification: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting |

Each task folder contains the dataset, `notebook.ipynb` (with a model-comparison `results_df` at the end), and a `README.md`.
